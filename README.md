# Dr. Papi Foundation

Public website for the Dr. Papi Foundation.

## Pages

1. `/` — Home
2. `/our-story` — Our Story
3. `/what-we-do` — What We Do
4. `/menodao` — MenoDAO
5. `/impact` — Our Impact
6. `/get-involved` — Get Involved
7. `/contact` — Contact

## Run

```bash
npm install
cp .env.example .env.local
npm run dev
```

Dev server: [http://localhost:3100](http://localhost:3100)

Copy `.env.example` to `.env.local` and set the API origin there. On Vercel, set the same keys as project environment variables. Never commit `.env`, `.env.local`, or other secret files.

Public contact addresses on the site are the Foundation inboxes (`info@`, `outreach@`, and `partnerships@` at the Foundation domain). Do not add unpublished mailboxes, phone numbers, or WhatsApp links until they are meant to be public.
