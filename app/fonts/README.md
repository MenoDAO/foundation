# Outfit

`outfit-latin-var.woff2` is the latin-subset variable build of **Outfit**
(weights 100–900), vendored so `next build` never has to reach Google Fonts.

- Upstream: https://github.com/Outfitio/Outfit-Fonts
- Served by Google Fonts as Outfit v15
- License: SIL Open Font License 1.1 — see `OFL.txt`

Do not rename or subset this file in place. If a new version is pulled from
Google Fonts, keep the `wght` range at 100–900 and keep the OFL notice with it.
